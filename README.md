# 🛡️ Malware Analyzer — Malware Awareness Lab

An interactive cybersecurity awareness website that demonstrates how **viruses, worms, and trojans** can affect computer systems through engaging animations and educational simulations.

## 🌐 Live Demo

🚀 **[Open Malware Analyzer](https://malware-analyzer-d7078.web.app/)**

## ✨ Features

- 🦠 **Virus Simulation** — Understand how viruses may spread between computer systems.
- 🪱 **Worm Simulation** — Visualize how worms can propagate across connected computers.
- 🐴 **Trojan Simulation** — Learn how trojans disguise themselves as legitimate software.
- 🎨 **Interactive UI** — Explore cybersecurity concepts through animations and visual effects.
- 📱 **Responsive Design** — Designed for an accessible experience across different screen sizes.
- ☁️ **Firebase Hosting** — Deployed online and accessible through a web browser.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layouts, and animations
- **JavaScript** — Interactive behavior and simulation logic
- **Firebase Hosting** — Website deployment and hosting

## 🎯 Project Objective

The goal of this project is to raise cybersecurity awareness by helping users understand common malware types and their potential impact on computer systems in a safe, simulated environment.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

### Deployment

This project is hosted using Firebase Hosting.

To deploy updates, install and configure the Firebase CLI, then run:

```bash
firebase deploy --only hosting
```

## ⚠️ Disclaimer

This project is intended **strictly for educational and cybersecurity awareness purposes**. All malware behavior is represented through simulated animations. The project does not create, distribute, or execute real malware and does not infect or damage actual computer systems.
