# ThreatLab PC — Cybersecurity Simulation Environment

A responsive, PC-style cybersecurity simulation dashboard for classroom learning about viruses, worms, and Trojans.

## Features
- Professional dark desktop dashboard with a simulated network topology
- Three mock endpoints and safe-state indicators
- Interactive virus, worm, and Trojan scenarios
- Standard and detailed educational event logs
- Event timeline, session counters, mock device state, and report export
- Responsive layout for desktop, tablet, and mobile
- No dependencies, backend, or build process

## Run locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Create a GitHub repository (for example, `threatlab-pc`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the URL shown in the Pages section.

## Safety
This project is an educational mock simulator. It does not contain or execute malware, access or modify files, connect to a network, scan devices, or install software. All endpoints and event logs are illustrative local state only.
